# AI Academic Risk Dashboard

An AI-powered academic dashboard designed to monitor and analyze student academic performance using attendance, marks, assignments, and other performance indicators.

> 🚧 This project is currently under active development.

## 📌 Project Overview

The AI Academic Risk Dashboard is designed to help faculty monitor student academic performance through a centralized and interactive dashboard.

The system focuses on academic indicators such as attendance, marks, assignments, and performance trends to help identify students who may require additional academic support.

The dashboard provides a structured view of academic information and allows users to explore course-wise and student-related data.

## ✨ Current Features

- 📊 Interactive academic dashboard
- 📚 Course-wise information
- 👨‍🎓 Student academic information
- 📈 Academic performance visualization
- ⚠️ Academic risk indicators
- 📝 Attendance and assignment information
- 🎨 Modern dashboard interface

⚙️ How to Run the Project

1. Clone the repository

2. Open the project folder
cd ai-academic-risk-dashboard

3. Install Flask
pip install flask

4. Run the application
python app.py

5. Open the application

Open the following address in your browser:

http://127.0.0.1:5000
